## Решение и открытый пункт

FDH выбран для учебного исследования интерпретируемости: синтетика разрешена
преподавателем, поля и метки описаны, есть время/история и фактически доступный образец.
Выбор не объявляется уже согласованным Ильёй или всей командой.

В raw на pinned commit есть README и data, отдельной LICENSE нет. У кода генератора
проверена GPLv3, но она не объявляется лицензией raw. Raw/CSV не публикуем.
Reviewer должен принять путь для полного набора: уточнить условия raw или согласовать
генерацию авторским кодом с соблюдением его лицензии. Это открытое замечание для Review.
