# Данные

raw — неизменённые исходники; interim — промежуточные результаты;
processed — данные после согласованных преобразований. Содержимое вне Git.
Перед добавлением: происхождение/право использования, PII review, data dictionary,
label availability, unit of observation, версия/checksum. Синтетические данные
проверяют pipeline, но не доказывают эффективность на реальном marketplace.
Ограничения и assumptions генерации фиксировать до экспериментов.
