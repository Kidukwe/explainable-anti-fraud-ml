# Frontend — MLAF-6

Для локального запуска нужны Node.js 22 и npm. Команды выполняются в Git Bash из каталога `frontend`.

```bash
npm ci
ENVIRONMENT=demo npm run dev
```

Открой адрес из терминала. По умолчанию это http://127.0.0.1:5173/. Если `ENVIRONMENT` не задан в процессе или файлах конфигурации, используется `demo`.

```bash
ENVIRONMENT=production npm run dev
ENVIRONMENT=production OPERATIONS_API_URL=/api/not-configured npm run dev
```

Первая команда показывает общий экран с сообщением об отсутствии настроенного API, если URL не задан в файлах. Вторая воспроизводит ошибку API и позволяет повторить запрос. Пустой успешный ответ с `dataset_version` и `items: []` отображается отдельно. Production использует настроенный API очереди, оценка модели пока недоступна. Для локальных настроек используй `.env.example` как образец. Переменные процесса имеют приоритет. После изменения настроек перезапусти dev-сервер или пересобери статический сайт. Публичный URL очереди не должен содержать секреты.

## Проверка demo

1. Открой № 10001 и проверь время, сумму без валюты, ID клиента и терминала.
2. Выбери «Готовый ответ — mock». Проверь оценку, порог, версии и отдельные блоки SHAP, LLM и проверок.
3. Выбери «Отказ проверки — mock». Карточка остаётся открытой, отклонённый текст скрывается, видны нарушение и шаблон SHAP.
4. Проверь «Загрузка», «Ошибка сети», «Модель недоступна», «Объяснение отсутствует» и «Ошибка проверки текста».
5. На готовом результате выбери другую операцию. До нового ответа должен отображаться только индикатор загрузки. В сценарии «Пустая очередь» карточка закрывается и счётчики обнуляются.

```bash
npm test
npm run build
```
