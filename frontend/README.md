# Frontend

Исходники интерфейса: `backend/static/` (HTML/CSS/vanilla JS), обслуживаются FastAPI.
Этот каталог — точка входа документации Fullstack-разработчиков, не второй build-проект.
Node/npm не нужны для командного сервиса. Fullstack 1 ведёт API/контракты,
Fullstack 2 — dashboard/доступность; интеграционные изменения ревьюят вместе.
Текущая страница показывает health и честное отсутствие ML-метрик.
Графики и просмотр предсказаний — будущие Issues после согласования данных.
React рассматривать отдельным ADR, когда сложность состояния UI это оправдает.
